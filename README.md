# MEDUSA Forensic Engine

Motor forense defensivo, reproducible e instalable en cualquier parte.
No es un solo detector. Es un debate de verdad.

## Estructura de Verdad / Debate

Variantes A/B/C como condicionales de operabilidad. El arbitro es engine/debate.py.

## Instalacion

git clone https://github.com/Tel4vivsempty/medusa-forensic-engine.git
cd medusa-forensic-engine
./install.sh

## Uso

python engine/debate.py
